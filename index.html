📖 使い方ガイド
MU 出欠管理ツールの操作方法
🚀 基本の使い方（4ステップ）
1
名簿管理でメンバーを登録する
「名簿管理」タブを開き、新しい名簿を作成からメンバーの名前を入力します。スペースや改行で区切ると別の人として登録されます。スプレッドシートからのコピペもOK。
Zoomの表示名が本名と異なる場合は 別名設定 に「本名=Zoom表示名」の形式で登録すると自動で照合されます。
2
定例開始から 5分後 に参加者テキストを取得する
Zoom の参加者パネルを表示した状態で、下記の方法でテキストをコピーします。5分後にスクリーンショットを撮ることで「5分以上の遅刻＝欠席」が自動的に判定されます。
3
「出欠確認」タブにテキストを貼り付けて実行
名簿を選択し、コピーしたテキストを貼り付けて「出欠を確認する」を押します。結果を確認・修正後、「アーカイブに保存」で記録を蓄積できます。
出席・欠席・特定困難のどのステータスも、結果画面の「ステータス変更」列から手動で変更できます。
4
この回の出欠をスプレッドシートの行にそのまま貼り付ける
結果画面の下部に「📊 この回の出欠をスプレッドシートにコピー」セクションがあります。
「ヘッダー付きでコピー」…1行目にメンバー名、2行目にTRUE/FALSE が入った形式でコピーされます。
「値のみ（TRUE/FALSE）」…すでにスプレッドシートに枠組みがある場合、1行分のTRUE/FALSEだけをコピーして、該当する行にそのまま貼り付けできます。
📋 出欠ステータスについて
出席テキストに名前が一致
欠席テキストに名前がない
特定困難部分一致または同姓同名
どのステータスの行でも「ステータス変更」列からボタンで変更できます。手動で変更した行は「元に戻す」で自動判定の結果に戻せます。保存済みのアーカイブの中身も同様に編集可能です。
🖥️ Windows でのテキスト取得（PowerToys）
1
PowerToys をインストール
Microsoft Store または github.com/microsoft/PowerToys からインストールします（無料）。
2
Text Extractor を起動
デフォルトのショートカット Win + Shift + T を押すと画面が暗くなります。
3
参加者パネルを範囲選択
Zoom の参加者一覧が表示されている部分をドラッグで囲むと、テキストが自動でクリップボードにコピーされます。
🍎 Mac でのテキスト取得　方法①：スクリーンショット標準機能
スクリーンショットを起動：⌘ Command+⇧ Shift+4
範囲選択カーソルが出たら、参加者パネルの文字が写っている部分をドラッグします。撮影された画像にカーソルを合わせると テキスト選択ボタン が出るので、全テキストを選択してコピーします。
🍎 Mac でのテキスト取得　方法②：ショートカットアプリで自動化（おすすめ）
💡 一度設定すると、範囲を囲むだけで即テキストがコピーされる最速の方法です。
Windows の PowerToys に近い感覚で使えます。
1
「ショートカット」アプリを起動する
Mac 標準アプリ（ひし形が重なったアイコン）を開き、画面上部の ＋（新規作成） をクリックします。
2
3つのアクションを順番に追加する
右上の検索窓から以下を探し、左側のエリアにこの順番で並べます。
「スクリーンショットを撮る」
「画像からテキストを抽出」
「クリップボードにコピー」
3
スクリーンショットの設定を「範囲指定」に変える ← ここが重要！
1番目の「スクリーンショットを撮る」の横の矢印を開き、設定を変更します。
フルスクリーン→インタラクティブ
選択部分→カスタム
4
好きなキーボードショートカットを割り当てる
画面右側の i（詳細） アイコンをクリックし、「キーボードショートカットを追加」を選択。
⇧ Shift+⌘ Command+X
使い方：設定したショートカット（例：Shift+Command+X）を押すと画面が暗くなり、範囲選択カーソルが出ます。文字がある部分をビッと囲むだけで、裏で自動的に文字がコピーされます。あとは貼り付けたい場所で Command + V するだけ！
📂 アーカイブ・スプレッドシート連携
1
毎回アーカイブに保存する
出欠確認後に「アーカイブに保存」を押すと、参加回・日付ラベルとともに記録が蓄積されます。保存後は入力画面に戻ります。保存後もアーカイブタブから内容を編集できます。
2
累積の集計マトリックスをコピー
アーカイブタブ下部の集計マトリックスに2種類のコピーボタンがあります。「ヘッダー付き」…回名・メンバー名を含む全体形式。「値のみ」…チェックボックスの値のみ。
3
欠席リスクの自動警告
欠席が 3回以上 で⚠️警告、5回以上 で⛔危険表示がアーカイブタブ上部に自動で出ます。
