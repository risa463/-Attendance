# MU 出欠管理ツール

Zoom の参加者パネルから取得したテキストを、事前に登録した名簿と照合して出欠を判定するブラウザ用ツールです。
名簿、出欠結果、アーカイブは各自のブラウザ内に保存されます。

## 使い方

1. `index.html` をブラウザで開きます。
2. 「名簿管理」タブで名簿を作成します。
   - スプレッドシートなどからメンバー名をコピーして貼り付けます。
   - 空白、改行、全角スペース区切りで登録できます。
3. Zoom の参加者パネルを表示し、OCR などで参加者一覧のテキストを取得します。
   - Windows は PowerToys の Text Extractor が利用できます。
   - Mac はスクリーンショット機能やショートカットアプリのテキスト抽出が利用できます。
4. 「出欠確認」タブで名簿を選び、取得したテキストを貼り付けます。
5. 「出欠を確認する」を押すと、出席、欠席、特定困難に分類されます。
6. 必要に応じて特定困難のメンバーを手動で出席または欠席に変更します。
7. 「値を取得（TRUE/FALSE）」を押すと、その回の出欠情報をスプレッドシートの✅に対応する形でコピーします。
8. 結果を残す場合は「アーカイブに保存」を押します。


開始から5分後など、判定したいタイミングで参加者一覧を取得すると、その時点で参加していないメンバーを欠席として扱えます。

## 主な機能

- 複数名簿の作成、編集、削除
- Zoom 参加者パネルのテキストと名簿の自動照合
- 出席、欠席、特定困難の件数表示と絞り込み
- 部分一致や同姓同名など、判定が難しいケースの注記表示
- 特定困難メンバーの手動分類
- 出欠結果のアーカイブ保存
- 欠席回数が多いメンバーの警告表示
  - 3回以上: 注意表示
  - 5回以上: 活動停止ライン表示
- 出欠マトリクスの表示
- Google スプレッドシート向けの TRUE/FALSE コピー

## 出欠ステータス

| ステータス | 意味 |
| --- | --- |
| 出席 | 名簿上の名前が参加者テキスト内で確認できた状態 |
| 欠席 | 名簿上の名前が参加者テキスト内で確認できなかった状態 |
| 特定困難 | 部分一致、同姓同名、不完全な OCR 結果などにより自動判定が難しい状態 |

## データ保存について

このツールはサーバーを使わず、ブラウザの `localStorage` にデータを保存します。

- 名簿データ: `mu_rosters`
- アーカイブデータ: `mu_archive`

同じ `index.html` でも、別のブラウザや別の端末では保存データは共有されません。ブラウザのキャッシュやサイトデータを削除すると、登録した名簿やアーカイブも消える場合があります。

## スプレッドシート連携

「アーカイブ」タブでは、保存済みの出欠結果から出欠マトリクスを作成できます。

- 「ヘッダー付きでコピー」: セッション名とメンバー名を含めてコピーします。
- 「値のみ（TRUE/FALSE）」: 出席を `TRUE`、欠席または特定困難を `FALSE` としてコピーします。

Google スプレッドシートに貼り付けると、チェックボックス管理用の値として利用できます。

## 注意点

- OCR の読み取り精度によっては、名前が正しく検出されないことがあります。
- 表記ゆれやニックネームは自動では完全に吸収できません。
- 同姓同名がいる場合は、必要に応じて結果を確認してください。
- 重要な出欠記録は、スプレッドシートなどにも転記して保管することをおすすめします。
